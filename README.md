# 오늘 우리, 어디 갈까? — 데이트 코스 추천 앱

지역과 원하는 분위기(특성)를 고르면, **이동 거리를 조절**해가며 조건에 맞는 데이트 코스를 짜주는 개인용 모바일 웹앱(PWA)입니다.

- 키 없이도 **시드 데이터로 바로 동작**합니다.
- 네이버/카카오 공식 API 키를 넣으면 **실제 장소를 자동 수집**합니다.
- LLM 키를 넣으면 코스 추천 멘트를 AI가 써줍니다(없으면 규칙 기반 문구로 대체).

## 빠른 시작

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 휴대폰에서 쓰려면 PC와 폰을 같은 와이파이에 두고
`http://{PC의 내부 IP}:3000` 으로 접속한 뒤, 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치됩니다.

## 쓰는 법

1. **지역** 선택 → 2. **원하는 분위기**(맛집/카페/산책/야경 등) 여러 개 선택 →
3. **동선 설정**에서 이동 거리 슬라이더로 코스 범위를 조절(가깝게↔넓게), 정거장 수·야경 포함 여부 선택 →
4. **코스 추천받기**. 추천된 각 코스는 순서·이동거리·예상 소요시간과 함께 표시되고, 장소 이름을 누르면 카카오맵으로 연결됩니다.

## 거리 조절(AI knob)

"이동 거리"는 코스의 장소 간 이동 합계 상한입니다. 추천 엔진(`src/recommend.js`)은 이 예산 안에서
태그 일치도와 거리를 함께 점수화해 동선을 구성합니다. 작게 잡으면 도보권으로 모이고, 크게 잡으면
한강·야경 명소처럼 떨어진 곳도 포함됩니다. 현재는 좌표 기반 규칙(하버사인 거리)으로 계산하며,
카카오/네이버 길찾기 API 키를 넣으면 `src/geo.js`의 `travelKm`을 실거리로 교체할 수 있습니다.

## 실제 장소 수집

`.env.example`을 복사해 `.env`로 만들고 키를 채운 뒤:

```bash
npm run collect
```

`scripts/collect.js` 상단의 `CONFIG`에서 지역/검색어/반경을 바꿀 수 있습니다.
카카오 REST 키만 있어도 좌표 포함 수집이 되고, 네이버 키가 있으면 설명이 보강됩니다.
수집 결과는 `data/places.json`에 합쳐지며, 서버는 요청마다 최신 파일을 읽으므로 재시작이 필요 없습니다.

## 폴더 구조

```
data/places.json     장소 데이터(시드 + 수집 결과)
src/geo.js           거리/시간 계산
src/recommend.js     코스 추천 엔진(규칙 기반)
src/llm.js           선택적 LLM 멘트 생성
server/index.js      Express 서버 + API
scripts/collect.js   네이버/카카오 장소 수집
web/                 모바일 PWA 프론트엔드
```

## API

- `GET /api/meta` — 지역·특성 목록, 기능 활성화 상태
- `GET /api/places?region=...` — 장소 목록
- `POST /api/recommend` — `{ region, tags[], distanceKm, stops, includeNight, useLlm }` → 추천 코스

## 메모

- 시드 데이터의 음식점·카페 이름은 동작 확인용 샘플입니다. 실제 상호는 `npm run collect`로 채우세요.
- 개인용을 가정해 로그인/계정은 없습니다. 필요하면 코스 저장 기능부터 추가하기 좋은 구조입니다.
