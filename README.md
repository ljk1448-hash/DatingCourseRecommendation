# 오늘 우리, 어디 갈까? — 데이트 코스 추천 앱

지역과 분위기를 고르면, 전국 어디서든 조건에 맞는 데이트 코스를 짜주는 개인용 모바일 웹앱(PWA)입니다.

## 주요 기능

- **전국 라이브 검색**: 17개 시/도 → 229개 시·군·구. 지역을 고르면 카카오 로컬 API로 그 동네를 즉석 검색해 코스를 구성합니다(미리 수집 불필요, 6시간 캐시).
- **분위기 태그**(맛집·카페·산책·야경 등 12종) 다중 선택 → 코스 3개 추천(식사→문화/액티비티→카페→산책→야경 흐름).
- **이동 수단**: 도보(거리 슬라이더로 범위 조절) / 차량(거리 무제한).
- **근교 허용**: 인접 시/도 대표 도시까지 후보에 포함(예: 대전→세종·청주).
- **블로그 후기**: 네이버 블로그로 장소마다 후기 한 줄 + 감성 태그 자동 보강.
- **코스 저장 + 지도/길찾기**: 마음에 든 코스 저장(♡), 코스 지도 보기(번호 마커+동선), 장소별 카카오맵 길찾기.
- **예산**(가성비/보통/프리미엄), **시간대 맞춤**(현재 시각에 안 어울리는 카테고리 제외), **비 오면 실내 위주**(Open-Meteo, 키 불필요), **가본 곳 제외**(장소 "다녀옴" 표시 → 다음 추천에서 제외).
- **코스 공유 + 이미지 저장**(카톡 등 공유 시트/PNG), **장소 바꾸기**(코스의 한 곳만 같은 종류 다른 곳으로 교체), **랜덤 추천**(🎲 아무거나), **현재 위치로 지역 자동선택**(GPS), **가보고 싶은 곳 찜**(가본 곳과 별개).
- **AI 추천 멘트**(LLM 키 있을 때), **비밀번호 보호**, **PWA**(홈 화면 설치·오프라인).

> 참고: 카카오 무료 로컬 API에는 가격·영업시간이 없어, **예산은 검색 성향(가성비/파인다이닝 등)**으로, **시간대 맞춤은 카테고리 영업시간 추정**으로 근사합니다(실시간 영업정보 아님). 날씨는 실제(Open-Meteo) 데이터입니다.

## 로컬 실행

```bash
npm install
npm start            # http://localhost:3000
```

`.env`(.env.example 복사)에 키를 넣으면 기능이 켜집니다. 휴대폰에선 같은 와이파이로 `http://{PC IP}:3000` 접속 후 "홈 화면에 추가".

## 환경변수

- `KAKAO_REST_API_KEY` — **필수**(라이브 검색, 카카오맵 활성화된 REST 키)
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` — 선택(블로그 후기·감성태그)
- `KAKAO_JS_KEY` — 선택(코스 지도 임베드, 사용 도메인 등록 필요)
- `LLM_API_KEY` (`LLM_BASE_URL`, `LLM_MODEL`) — 선택(AI 멘트)
- `APP_USERNAME`(기본 date), `APP_PASSWORD` — 접근 비밀번호(나만 쓰기)
