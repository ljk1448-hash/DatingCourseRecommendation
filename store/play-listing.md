  - 계정·이름·연락처: 수집 안 함

## 4. 업로드 단계
1. Play Console → **앱 만들기**: 이름, 언어(한국어), 앱, 무료 선택, 정책 동의.
2. 왼쪽 메뉴 **테스트 → 내부 테스트**(가장 빠름) → **새 버전 만들기**.
3. **app-release.aab** 업로드: `android/app/build/outputs/bundle/release/app-release.aab`
4. 출시명/출시노트 입력 → 저장 → 검토 → 출시. 내부 테스터(본인 이메일) 추가하면 링크로 바로 설치 가능.
5. 대시보드의 **앱 설정 체크리스트**(3번 항목들)와 **스토어 등록정보**(1·2번)를 모두 채움.
